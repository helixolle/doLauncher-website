doLauncher

doLauncher is a text-based Android launcher with essential apps, floating folders, search, an agenda, task lists and Markdown notes.

Requires Android 8.0 or later.

Home screen

Choose which apps appear on Home, rename their labels and arrange them in a text list. The clock and date sit above an agenda with calendar events, the next alarm and scheduled tasks.

Text size, alignment and app placement can be adjusted. Light, dark and pure-black themes are available.

The optional step summary requires a supported sensor and permission. Counting is active while the launcher is visible, rather than continuously in the background.

Floating folders

Group apps under a folder label. Tapping the label opens a floating horizontal row of apps while the rest of Home stays in place.

Select an app to launch it, or tap outside the folder to close it.

Pull-down search

Drag down on Home to open search. Results are grouped into apps, app shortcuts and contacts, and update as the query changes. Swipe up to return to Home.

Contact search is optional and requires permission. Call and message actions open the dialer or SMS composer.

The screenshots show an empty search, a query matching several types of result, and a more specific query matching one app.

Tasks and routines

The Tasks screen has an Inbox and custom lists. Add and complete tasks, move them between lists, and reorder tasks and lists.

Routine lists can reset on a repeating schedule. A task can also have a date and time so it appears in Home’s agenda.

Task dates do not trigger a notification or sound. Repeating resets apply to lists, not individual tasks.

Markdown notes

Pull down again from Search to open a note in the same field. The formatting toolbar adds headings, emphasis, lists and checklist markers.

Save the note as a .md file in a folder you choose. Closing the editor keeps the unfinished draft for later.

Screenshots are rendered from the Android interface with sample data, not captured from a device. Search and Notes include an illustrative keyboard, not a keyboard provided by the launcher.
